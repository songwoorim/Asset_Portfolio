# 자산 포트폴리오 통장 (Asset Portfolio)

개인용 투자 포트폴리오 대시보드. 단일 HTML 파일 하나(`index.html`)로 완결되며 GitHub Pages로 호스팅됩니다.

**🔗 배포 사이트: https://songwoorim.github.io/Asset_Portfolio/**

---

## 개요

해외주식(14종목) · ISA(2종목) · 연금저축(2종목) · 예수금(USD+KRW) 4개 계좌를 통합 추적합니다.
실시간 시세는 Finnhub(무료 키) + open.er-api(환율, 무료·키 불필요)로 클라이언트에서 직접 fetch 합니다.

- **설계 기준**: iPhone 16 Pro 모바일 우선
- **디자인 언어**: Apple 스타일 (화이트/파치먼트 + Action Blue `#0066cc`)
- **빌드 불필요**: 별도 번들러/서버 없이 `index.html` 하나로 동작

## 화면 구성 (하단 고정 탭 5개)

| 탭 | 내용 |
|---|---|
| **홈** | 표지(총자산·당일/총수익 칩·자산배분 그리드) → 종목별 보유비중 → 수익률 히트맵 → 시장지수 → 환율 → 통화노출 |
| **손익** | 수익 현황 → 자산 추이(스크럽 그래프) → 벤치마크 비교(vs S&P500) → 월간·연간 리뷰 → 실현손익 |
| **보유** | 계좌별 보유 종목(해외주식/ISA/연금저축) → 예수금 → 자산배분 도넛 → 종목별 비중 → 섹터·테마 → 종목별 손익률 |
| **리밸런싱** | 리밸런싱 제안 → 체크포인트(17행 슬라이더) → 양도세 시뮬레이터 → What-if 매수 시뮬레이터 → 진단 |
| **이력** | 거래이력(198건, 필터) → 종목 뉴스 |

## 변경 이력

### 계좌 보유 목록: 테이블 → 카드형 전환
- 해외주식/ISA/연금저축 3개 계좌의 `<table class="acct-table">` 구조를 **종목당 카드 하나(`.hcard`)** 리스트로 전면 교체
- 카드 구성: 로고 + 종목명 + 수량 / 평가금액 + 누적수익률(위쪽 줄) → 점선 구분 → 현재가 + 당일등락 배지(아래쪽 줄)
- 상단 요약을 `매입금액 OOO원 · 평가손익 +OOO원(+OO%)` 한 줄 텍스트에서 **매입금액 칩 + 평가손익 칩** 2개로 분리 (부호별 색상 자동 전환, 표지 `.cover-chip`과 동일한 디자인 언어)
- 현재가/당일등락은 `HEAT_LIVE` + `DAY_CHG[ticker]`가 있을 때만 표시, 없으면 "실시간 갱신 시 현재가 표시" 빈 상태 처리
- 좁은 화면에서 컬럼이 깨지던 문제의 원인이었던 `.acct-table` 모바일 미디어쿼리 규칙 일괄 정리
- 수정 중 `wonPlain()`이 이미 "원"을 포함하는데 템플릿에서 중복으로 붙던 버그(`원원`) 발견 및 수정

### 수익 현황(`#sec-daily`) 리디자인
- **히어로 카드** 도입: 손익 금액을 부호별 색조 배경 카드에 크게 표시
- 알약형 기간 탭(오늘/이번주/이번달/이번분기/올해/총)을 **세그먼트 컨트롤** 스타일로 교체 (마크업·로직 변경 없이 CSS만 교체)
- **베스트/워스트 스포트라이트** 추가: 해당 기간 최고/최저 기여 종목 2개를 카드로 강조
- **기여도 바 리스트** 추가: 중앙선 기준 좌(하락)/우(상승)로 뻗는 막대로 종목별 손익 기여 규모를 시각화
- 베스트/워스트로 뽑힌 종목도 아래 전체 기여도 리스트에 **중복 포함**
- 리스트 행 사이 구분선(`border-bottom`) 제거 → 여백으로만 구분
- 부수 효과: 기존에 `.pnl-name` CSS가 중복 정의돼 서로 덮어쓰던 문제가 새 `dp-` 프리픽스 분리로 해소됨

### 섹션 헤더(`page-head`) 아이콘 전면 교체 — 22개 섹션
- 텍스트 기호(`☀ ▦ ◠ ⚔ ◷ ⌸` 등)를 **SVG 라인 아이콘 + 소프트 컬러 원형 배지**로 전면 교체
- 섹션 성격별 색상 체계 도입:

  | 색상 | 대상 섹션 |
  |---|---|
  | 🔵 파랑 | 보유비중, 자산추이, 자산배분, 통화노출, 섹터·테마 비중 |
  | 🔴 빨강 | 수익률 히트맵, 수익현황, 벤치마크 비교, 월간·연간 리뷰, 종목별 손익률, 실현손익 |
  | 🟣 보라 | 시장지수, 실시간 환율, 종목 뉴스 |
  | ⚪ 회색 | 거래 이력 |
  | 🟢 초록 | 리밸런싱 제안·체크포인트, What-if 시뮬레이터, 양도세 시뮬레이터, 진단 & 조언 |

- 계좌 헤더(해외주식/ISA/연금저축/예수금)는 숫자(`01`~`04`) 대신 **기존 `ACCT_ICONS`(지구본/집/새싹/현금)를 재사용**하고 각 계좌 고유 색상을 소프트 배경으로 적용 → 자산배분 그리드와 시각적 통일

### 월간·연간 리뷰(`#sec-review`) 리디자인
- **인터랙티브 히어로**: 카드를 탭하면 히어로의 라벨·숫자·색상·진행바가 해당 지표 상세로 전환 (기본값 = "올해 자산 성장")
- 기존 6개 지표를 **아이콘 스탯 카드 2열 그리드**로 재구성
- **보너스 인사이트 6종 신규 추가** — 모두 기존 `RV.months` 실거래 데이터에서 직접 계산 (새 데이터 소스 없음):
  - 최고 매수월 / 매수 연속 개월(스트릭) / 최고 상승월 / 올해 총 매도 / 올해 최다매수 종목 / 원금 대비 배율
- 보너스 카드는 기본 접힘 상태이며 **"재미있는 인사이트 더보기" 토글**로 펼침 (앰버 톤으로 핵심 지표와 시각적 구분)
- 별도로 있던 **총자산 / 증감 / 매수금액 3개 막대그래프를 세그먼트 탭 1개로 통합** (기존 "증감으로 보기" 토글 버튼 제거)
- 히어로 진행바는 각 지표별로 의미 있는 비율을 표시 (예: 이번 달 매수 → 올해 매수 누적 대비 비중)

### 시장 지수(`#sec-market`) 리디자인
- 텍스트뿐이던 지수 카드에 **지수별 라인 아이콘** 추가 (S&P500·NASDAQ·DOW·SOX는 보라, KOSPI는 블루로 국내/해외 구분)
- **절대 포인트 변동** 추가 표시 (기존 %변동에서 역산, 새 데이터 불필요) — 예: `+31.68pt`
- **강도바** 추가: 각 카드 하단에 변동폭 크기를 ±2% 기준 스케일로 시각화, 큰 변동(코스피 등)은 바가 꽉 참
- **미국 3대 지수 평균 + 코스피 디커플링 인사이트 배너** 추가 — 국내외 흐름이 갈릴 때 자동으로 문구 전환
- **VIX 전용 게이지 카드** 신규: 안정(0-20)/주의(20-30)/공포(30+) 3단 그라디언트 게이지로 변동성 상태를 직관적으로 표시
- **필라델피아 반도체지수(SOX) 신규 추가** — Finnhub에 지수 심볼이 없어 기존 S&P·나스닥·다우와 같은 방식으로 **ETF 프록시(SOXX)** 실시간 시세로 대체
- **환율 카드 추가**: 시장지수 그리드 안에서 USD/KRW 환율을 요약 카드로 함께 확인 가능 (하단의 상세 환율 섹션과는 별개로 유지)

### 거래이력 리디자인
- 기존 밋밋한 날짜순 나열(드롭다운 필터 하나 + 단순 행)을 **히어로(매수/매도 비율) + 인사이트(show/hide 토글) + 월별 그룹 타임라인**으로 전면 개편
- **히어로**: 전체 199건 중 매수 196건(98.5%) · 매도 3건(1.5%) 비율바로 "장기 보유 위주" 매매 성향을 바로 보여줌
- **인사이트 영역**(기본 펼침, 토글 가능): 이번달 매수(`RV.thisM` 재사용) · 최다거래 종목(거래 횟수 기준) · 건당 평균 거래 · 총 거래대금 · 최근 6개월 매수 추이 미니 막대그래프(이번달만 다른 색으로 강조)
- **타임라인**: 왼쪽 세로선 + 월별 그룹 헤더, 각 항목에 실제 종목 로고(`txAvatar()` — 기존 아이콘/커스텀로고/계좌색 우선순위 체인 재사용) + 매수(+)·매도(−) 아이콘 배지, 금액은 `won()`으로 ₩ 기호 포함 표시
- **필터**: 계좌 세그먼트 탭(전체/해외주식/ISA/연금저축) + 개별 종목 선택 드롭다운을 함께 제공, 두 조건은 AND로 결합
- **스크롤 등장 효과**: 타임라인 각 항목이 화면에 들어올 때 아래에서 떠오르며 나타남(개별 아이템 단위 IntersectionObserver, 페이지 섹션 단위의 기존 `revealPanel()`과는 별도)
- 항목 클릭 시 기존 바텀시트 모달(`openModal()`)로 연결
- 죽은 CSS(`.tx-filter`, `.tx-count`, `.tx-scroll`, `.tx-row`, `.tx-d`, `.tx-ic`, `.tx-m`, `.tx-a`)와 인쇄모드의 `.tx-scroll` 오버라이드 정리

- **스크롤 박스**: 타임라인 전체가 최대높이 420px 자체 스크롤 박스(`#txListScroll`)로 분리 — 199건이 한 페이지에 다 풀리지 않도록 함(첫 배포 때 누락했던 부분, 추후 수정). 스크롤 등장 효과의 관찰 기준(`root`)도 뷰포트 대신 이 박스로 변경, 필터 변경 시 스크롤 위치 자동 리셋

### 추가 인터랙션 효과 5종
- **스켈레톤 + 시머**: 새로고침 시작 시 계좌 카드 평가액(`.hcard-ev`)·히트맵 값(`.pnl-val`)에 반짝이는 회색 스켈레톤 적용, `renderAll()`이 새 값으로 교체하면서 자연스럽게 사라짐
- **갱신 값 플래시**: 새로고침 완료 직후, 방금 갱신된 `.hcard-ev`/`.pnl-val`이 오르면 빨강·내리면 파랑으로 짧게 반짝였다 사라짐 (기존 up/down 클래스를 그대로 활용해 방향 판별)
- **모달 바텀시트 슬라이드업**: 종목 상세 모달을 기존 "즉시 표시"에서 배경 페이드인 + 카드가 아래에서 위로 슬라이드업되는 방식으로 전환. `showModal()`/`hideModal()` 공용 헬퍼로 열기·닫기 3곳(닫기 버튼·배경 클릭·거래이력 이동) 전부 통일
- **당겨서 새로고침**: 페이지 최상단(`scrollY<=0`)에서 아래로 당기면 인디케이터가 나타나고, 임계치 이상 당긴 뒤 놓으면 기존 새로고침(⟳) 버튼과 동일한 `refresh()`가 실행됨. 기존 버튼은 그대로 유지, 보조 제스처로 추가
- **버튼 리플**: 새로고침·설정 등 아이콘 버튼과 하단 탭바 버튼에 클릭 지점에서 파문이 퍼지는 효과 추가

### 월간·연간 리뷰 히어로 카운트업
- 인사이트 카드 12개 클릭 시 히어로 영역의 **제일 큰 폰트(27px) 숫자**가 0에서 목표값까지 부드럽게 카운트업 (ease-out, 450ms)
- 카드 12개 중 10개(이번달 매수·올해 매수 누적·올해 자산성장·1년전 대비·올해 실현손익·12개월 매수·매수 연속 개월·최고 상승월·올해 총 매도·원금 대비 배율)는 원화 금액·퍼센트·배율·개월수 등 실제 숫자라 카운트업 적용
- 2개(최고 매수월·올해 최다매수 종목)는 각각 "2024년 12월", "마이크로소프트"처럼 **텍스트값**이라 카운트업 대상에서 제외하고 즉시 전환되도록 분리 처리
- 카드마다 단위(원/%/배/개월)가 달라서, 이전 카드의 값에서 이어서 세지 않고 매번 0에서 시작하도록 설계 — 단위가 다른 두 숫자 사이를 억지로 보간하면 시각적으로 부자연스러워지는 문제를 피함

### 스크롤 등장 효과 개선 (한번에 다 나오던 문제 수정)
- 기존엔 페이지 전체 18개 섹션을 한 번에 관찰(observe)해서, 홈 탭처럼 섹션이 촘촘히 붙어있으면 스크롤을 살짝만 해도 여러 개가 동시에 감지되어 "한번에 다 나오는" 것처럼 보이는 문제가 있었음
- **패널 단위로 분리**: `revealPanel(panelName)` 함수가 해당 탭(`data-panel`)의 섹션들만 새로 관찰하도록 재작성. `threshold`/`rootMargin`도 더 엄격하게 조정해서 실제로 화면에 충분히 들어와야 등장하도록 수정
- **탭 전환 시 재생**: 하단 탭바를 눌러 다른 화면으로 이동하면 그 탭의 섹션들을 "아직 안 나타난 상태"로 리셋하고 다시 관찰 시작 — 같은 탭을 반복해서 오갈 때마다 등장 효과가 매번 재생됨. 단, 같은 탭 안에서 스크롤을 위아래로 반복하는 것만으로는 재생되지 않음(한 번 나타난 섹션은 그 탭 안에 머무는 동안엔 유지)

### 인터랙션 효과 7종 추가
확인해보니 4개(카운트업 확장/스케일 눌림/실시간 펄스/새로고침 체크)는 이미 이전에 반영돼 있었고, 이번엔 나머지 3개를 마무리했습니다.
- **세그먼트 필 슬라이드**: 수익현황 기간탭(`#pnlTabs`)·자산추이 기간탭(`#trPeriods`)·종목별 보유비중 스코프탭(`#swSeg`) 3곳에 공용 헬퍼(`initSegPill()`/`positionSegPill()`) 적용 — 탭을 누르면 흰 배경이 순간이동 대신 옆으로 미끄러지듯 이동. 처음엔 숨겨진 탭(`display:none`) 안에 있어 폭 계산이 0으로 나오는 문제가 있어, 하단 탭바 전환 시 순간이동 모드(`instant`)로 위치를 재보정하도록 처리
- **도넛 그려지는 애니메이션**: 공유 함수 `donutSVG()`(자산배분·섹터비중에서 사용)에 이미 마련돼 있던 `.donut-arc-draw`/`data-dash` 마크업에 CSS 트랜지션 규칙을 추가하고, 두 호출부(`renderAllocDonut`, `renderSectorAlloc`)에서 `animateDonutArcs()`를 실제로 호출하도록 연결. 종목별 보유비중 도넛(`swRenderDonutBase`)은 개별 `<path>` 구조라 stroke-dasharray 방식 대신 opacity 페이드인 + 항목별 미세 딜레이로 구현 — 기존 클릭 시 팝아웃(transform 기반)과 충돌하지 않도록 트랜지션 속성을 분리
- **스크롤 등장 효과**: `.page.collapsible` 18개 섹션에 `IntersectionObserver` 기반 1회성 fade-in-up 적용. JS가 `.scroll-ready` 클래스를 붙여야만 opacity:0으로 시작하는 구조라, JS 실패 시에도 콘텐츠가 영구히 숨겨지지 않도록 안전장치를 이중으로 마련(클래스 미부여 시 항상 보임 + 3초 타임아웃 강제 표시)

- **최고점 마일스톤 마커**: 전체 기간 중 자산 최고점이 현재 선택된 기간(예: 1년) 범위 안에 들어올 때만 그래프 위에 마커+라벨(`최고점 ₩84,110,438`)로 표시

### 국내·해외 실시간 시세 연동 (한국투자증권 KIS API)
- **Cloudflare Worker 프록시 구축**: KIS APP_KEY/APP_SECRET을 서버 사이드(Cloudflare Secret)에만 보관, 브라우저에는 절대 노출되지 않도록 분리
  - `POST /oauth2/tokenP`로 발급받은 액세스 토큰을 Cloudflare KV에 캐싱(24시간) — 매 요청마다 재발급 방지
  - `GET /quote/domestic?codes=...`, `GET /quote/overseas?codes=...` 두 개의 읽기 전용 엔드포인트만 제공(주문 API는 프록시에 아예 구현하지 않음)
- **갱신 방식: 5초 자동 폴링 → 기존 새로고침(⟳) 버튼 클릭 방식으로 전환**
  - 처음엔 5초 간격 자동 폴링으로 구현했으나, 페이지 진입 시 스냅샷 값이 잠깐 보였다가 실시간 값으로 바뀌는 부자연스러운 전환이 발생 + 토스증권처럼 "새로고침 시점에 갱신"되는 방식이 더 자연스럽다는 판단으로 원복
  - `fetchKisDomestic()` / `fetchKisOverseas()` 두 함수를 기존 `refresh()` 파이프라인(환율·지수·뉴스와 동일한 자리)에 작업으로 추가 — 버튼 한 번으로 국내 ETF 4종목·해외주식 14종목·환율·지수·뉴스가 한 번에 갱신됨
  - `coverTotal`(총자산)은 평소엔 전일 종가 기준 스냅샷 값을 그대로 유지하고, ⟳ 버튼을 누른 시점에만 최신 값으로 갱신
- 해외주식 API 응답의 전일대비(`change`)와 등락률(`changePct`) 부호가 서로 불일치하는 경우가 있어(하락 종목인데 대비값은 양수로 오는 케이스), 등락률 부호 기준으로 대비값 부호를 보정하는 로직 추가(Worker 쪽에 반영)
- 기존 Finnhub 기반 "미국주식" 수동 새로고침 기능은 제거(KIS가 동일 데이터를 더 정확하게 커버) — Finnhub은 지수·뉴스 갱신 용도로만 유지
- **총자산(coverTotal) 카운트업 애니메이션**: 새로고침 시 이전 값에서 새 값까지 부드럽게 롤링되며 안착(ease-out, 도중에 값이 또 바뀌어도 0으로 리셋되지 않고 이어서 전환)
- 실제 KIS Developers 개인 신청 기준 검증 사항:
  - 모의투자 계좌는 연속 호출 시 API 제한이 낮아, 반복 호출이 잦은 용도는 **실전투자 계좌** 키 사용 권장 (시세 조회 전용이라 주문 위험 없음)
  - 개인/HTS ID 신청 트랙은 법인 제휴 트랙과 달리 허용 IP 화이트리스트 등록이 필요 없어 Cloudflare Workers 같은 동적 IP 프록시와 궁합이 좋음

### 예수금 리디자인 (전체 현금 통합형)

### 종목별 보유비중 리디자인
- **스코프 탭 3개 신규**: 전체 자산 / 해외주식 / 국내 ETF — 예수금까지 포함한 전체 그림부터 계좌별 세부 비중까지 좁혀볼 수 있음
- **도넛 세그먼트 클릭 인터랙션**: 조각이나 리스트를 탭하면 해당 종목이 상단 상세(로고·이름·비중%·평가액·수익률)로 전환. 선택된 조각은 `transform: translate()`로 부드럽게 튀어나옴(스프링 이징) — 매번 SVG를 다시 그리지 않고 기존 엘리먼트의 transform만 갱신해서 실제로 애니메이션이 재생되도록 구현
- **숫자 카운트업 애니메이션**: 종목 전환 시 %가 이전 값에서 새 값으로 부드럽게 굴러가며 바뀜 (ease-out, 320ms)
- **선명한 팔레트 신규 도입**: 기존 파치먼트 톤 대신 블루→핑크→틸 계열의 선명한 색상 세트(`SW_PAL`)를 이 섹션 전용으로 사용 — 19개 조각까지 늘어나는 "전체" 탭에서도 구분이 잘 됨. 종목 로고는 기존 3단계 우선순위(Simple Icons → CUSTOM_LOGOS → 컬러 이니셜) 그대로 재사용
- **인사이트 영역**: "최대 비중 vs 최소 비중" 히어로 카드 + "상위 3개 집중도"·"핵심 포지션(5% 이상 종목 수)" 통계 칩 2개. **show/hide 토글**로 접고 펼 수 있으며 기본값은 열림
- **리스트 자체 스크롤 분리**: 종목 리스트만 최대높이 252px의 자체 스크롤 박스로 분리해서, 리스트를 내려도 위쪽 도넛·인사이트는 항상 고정되어 보임 (기존 "전체보기" 접기/펼치기 버튼은 필요 없어져서 제거)
- 스크롤 박스 내 가로 스크롤 버그 수정 — 리스트 행의 호버 배경 확장용 음수 마진이 스크롤 박스 밖으로 삐져나가던 것을 `overflow-x:hidden`으로 차단

## 알려진 버그 패턴 (재발 방지 메모)

- **스크립트 실행 순서** — HTML 요소를 `<script>` 태그보다 뒤에 넣으면 해당 요소를 참조하는 이벤트 바인딩이 전부 무효화됨. 새 DOM은 항상 `<script>` 앞에 배치할 것
- **CSS 중복 규칙** — 같은 선택자를 리팩터링 중 남겨두면 나중 규칙이 이전 규칙을 덮어써서 의도치 않은 스타일이 되살아남. 큰 리디자인 후엔 `grep -c ".foo{"`로 중복 정의 확인
- **`data-panel` 미부여** — 새 섹션 추가 시 `data-panel` 속성을 빠뜨리면 탭 전환과 무관하게 항상 노출됨
